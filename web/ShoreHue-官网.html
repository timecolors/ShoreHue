海床

屏幕边缘的那些面板，只是露出水面的部分。
海床是它们的底层：整个 ShoreHue 的设置模型在这里被摊开成一张配置树， 每个节点都能生成可执行的 C# 代码，每个功能都能改写。 你不必接受作者给的那几个小组件 —— 你可以自己长。

配置即代码

设置不是一堆开关，而是一棵可读、可改、可版本管理的配置树。每个节点都能生成对应的 C# 配置代码，逐字段带中文注释。

单预设闭环

保存当前节点 → 应用时编译执行、写回生效。被覆盖的内置设置会自动变灰，双击即可解除该处覆盖，原始值立刻回来。

整套预设

全量配置快照的保存 / 应用 / 删除。被预设覆盖的设置页、海床树、预设列表三处联动标记，一眼看出哪些被动过。

完全编程

小组件与面板支持完整的 .xaml + .xaml.cs（WPF 用户控件）——事件、数据绑定、样式全部可用，不只是填参数。

实时预览

VS Code 式的双编辑器 Tab 切换，保存即编译并即时预览；编译报错内联显示在编辑器里，不用切窗口看日志。

功能模板

计时器、计算器、划词翻译、剪贴板、便签等小组件模板，以及通知坞、最近使用、快捷设置等面板模板，可保存为变体后分配到任意区域。

文件夹即真相源

设置与功能按 常规 / 区域 / 面板 / 动画 组织成真实的文件夹与文件。直接用你惯用的编辑器改，保存即时生效——海床本身就是个可视化文件管理器。

状态栏与动画插件

写一个实现 IStatusProvider 的 C#（CPU 温度、网速…）放进 seabed\状态栏\ 自动挂载；实现 IAnimation 放进 seabed\动画\，就能在设置里选作呼出动画。

AI 协同

描述需求 → AI 生成 C# → 编译 → 应用。海床内置「AI 编程指南」，讲清楚能做什么、不能做什么、两种模式与文件格式。

一句话

别的工具让你配置它；ShoreHue 让你改写它。 海床就是这个「改写」的入口——也是为什么它被放在页面最深处： 你得先潜下去，才看得到。
