# ShoreHue 海岸线 — 版本发布说明

> 版本号遵循 x.y.z 语义化版本。本文件记录各版本新增功能与改进。

---


## v1.1.1（最新版本）

> 本版是**安全与可靠性加固**：修掉信任模型里的一条自授权通道、三条会静默丢数据的路径，
> 并把 CI 的包校验提到与客户端完全同判（顺带发现三个此前"CI 绿、装上去是坏的"市场包）。
> 同时加固了两条**会动用户机器**的路径 —— **卸载**（不再可能删掉你自己的文件）与**自动更新**的挑包逻辑。

### 新功能

**1. 任务栏：窗口标签分组**
- 多个窗口标签可**合并成一组**：组图标是成员图标的 2×2 拼版 + 成员数角标；鼠标悬停展开成员、移开收起
- 最多嵌套两层（第二层留了个小彩蛋）；右键可解散；分组按 exe 路径持久化；成员少于 2 个时自动散开

**2. 海床：内置件「文件化」（本版海床最大的变化）**
- 6 个内置小组件（timer / calculator / clipboard / note / web / textai）与 7 个面板功能
  （通知坞 / 最近使用 / 快捷设置 / 窗口控制 / 任务栏 / AI / 应用辅助）改为**从 seabed 文件夹加载**：
  改文件夹里的代码会真正生效，不再是"改了没用"
- 编译失败时**保留上一份可用实例**，从未成功过才回退 exe 内置（界面会显示加载问题，不静默）
- 内置模板会**随版本升级**（只覆盖你没动过的文件，你改过的不动）

**3. 海床：文件管理器增强**
- 按名字全深度筛选、树首次默认全展开；F2 重命名、Del 删除、Ctrl+S 保存、Ctrl+N / Ctrl+Shift+N 新建、F5 刷新
- 支持从资源管理器**拖文件进来**；右键可新建文件/文件夹、重命名、删除、打开
- 右侧**实时 XAML 预览**；底部状态提示不再被按钮挤掉

**4. 崩溃防护与安全模式**
- 连续 3 次未正常退出 → 自动以**安全模式**启动（跳过海床插件、设置覆盖与自定义动画），
  托盘菜单也可手动「以安全模式重启」——不会再因为一个坏插件而打不开
- 插件连续异常会**自动熔断停用**（3 次 / 60 秒内），插件报错不再弹模态框拖垮整个界面

**5. 组件市场**
- 官方包显示金色「★官方」徽章；包要求的 `apiVersion` 高于你的客户端时**明确拒绝并提示升级**，
  而不是装上去才出错
- 每个组件可在「默认沙箱 / 受信任」之间手动切换（信任只对当前内容有效，内容一改自动失效）
- 加载失败的组件在设置列表里带 ⚠ 标记

**6. 便签**
- Ctrl+F 搜索（标题 + 正文）、置顶、换色、重命名、复制一份、**删除后 8 秒内可撤销**
- 面板内快捷键（新建 / 删除 / 切到下一个）可在设置里改，冲突会提示；默认颜色改为跟随面板背景

**7. 剪贴板**
- 键盘操作：↑↓ 选择、Enter 复制、数字键快选、Del 删除；显示来源应用（「已复制 · 来自 xxx」）
- 支持**粘贴为纯文本**；复制 A→B→A 时旧条目去重置顶；设置里的预览行数改为 1–20 行

**8. 通知坞**
- 通知**按应用分组**，每条可单独关闭（✕）

**9. 其他**
- 划词翻译新增**目标语言**设置与**翻译历史**（点一条即复制）；计算器新增**历史记录**
- 面板尺寸新增**黄金长宽比自适应**（长边 = 短边 × 黄金比例），并修掉底部页脚被裁切
- 快捷设置面板新增**性能模式**切换（顺滑 / 正常 / 省电 / 自定义）

### ⚠ 升级注意：海床目录变扁平了
- 内置面板不再待在 `面板\小组件\` 与 `面板\面板功能\` 两层里，改为平铺成 `面板\<id>\`
- 迁移**只移动、不删除**，目标已存在则跳过

### 安全
- **修复插件自授权通道（严重）**：`HostCapabilities.Settings` 交出的接口上曾带着整表替换入口
  `Apply(SettingsData)`，而 `SettingsData.TrustedPlugins` 是公开可写属性 —— 外来插件可以
  `Apply(new SettingsData { TrustedPlugins = { [自己] = 内容哈希 } })` **给自己登记信任并落盘**，
  下次加载直接跳过整个沙箱。现已把 `Apply` / `Reload` / `SaveSettings` / 自定义面板整表写入
  从对外接口移到 internal 的宿主面（`ISettingsHost`），并加了结构性守卫测试。
- **修复信任表可被预设 / 云端配置 / `.shpkg` 包注入**：这三条"外部数据 → 配置 → 落盘"的通路
  以前都会保留文件里写的 `TrustedPlugins`，一条记录即可让受害机上的外来包永久免检
  （与文档承诺的"预设不能替代码授信"相矛盾）。现在统一经 `PluginTrustSanitizer` 与本机既有
  信任表求交，只保留 id 与哈希都完全一致的记录。
- **补齐沙箱"宿主写文件"通道**：`SettingsFileManager.Save(data, path)` 是公开静态且收任意路径，
  `PresetManager` 也会写盘 —— 二者此前都不在黑名单里，等于绕过 `File.Write*` 白名单的任意写文件通道。
- **补 DNS 外带通道**：`Dns.GetHostAddresses(读到的内容)` 既不是 Socket 也不是 HttpClient，
  以前三层都判不出"本地数据 → 网络出口"。
- **文本层与执行文本对齐**：海床「完全编程」保存时曾把 `.xaml` 与 `.xaml.cs` 拼成一个字符串
  只传给沙箱的第一个参数，导致受限 XAML 方言校验在这条路径上完全不跑。
- **内置件覆盖分支补闸门**：id 为已迁移内置件（如 timer）的文件夹此前不走沙箱。

### 修复
- **「应用整套预设 / 一键恢复 / 云端恢复」静默失效（数据丢失级）**：`SettingsManager.Apply`
  落盘后没有清"脏"标记，下一次 `Reload()` 会把内存里的旧快照写回去，覆盖掉刚刚写入的文件 ——
  界面照样提示成功。已修并补回归测试。
- **云端恢复不再可能毁掉全部设置**：改为先反序列化校验 → 留 `.preRestore.bak` → 走原子写；
  以前是 `File.WriteAllText` 直接覆盖，一份 HTML 错误页就能让配置全丢且无法找回。
- **空闲 CPU 从 8.6% 降到约 2.6~3.4%（单核）**：主因是状态栏每秒调用一次
  `NetworkInterface.GetIsNetworkAvailable()` —— 实测 **78ms/次**（内部枚举全部网络适配器）。
  同时修掉：通知坞从启动起就在 UI 线程按 800ms 遍历所有顶层窗口（面板从没打开过也不会停）、
  通知中心 SQLite 轮询占用 UI 线程、每次扫描每个窗口重复 4 次 `GetSystemMetrics`。
- **内存/事件泄漏**：通知坞每次切换泄漏一个视图（静态事件从不退订）、媒体播放器离开可视树后
  DWM 缩略图与定时器继续跑、字号管理器强引用每个遍历过的元素、剪贴板/便签小组件不退订单例服务、
  AI 面板关闭后仍以 4 次/秒轮询光标输出。以上均已收尾。
- **计时器小组件**：定时器以前在构造函数里启动且永不停止（每秒醒 4 次）；倒计时结束时
  「时间到」状态与提示音/通知**永远不可达**（界面停在"计时中… 00:00"）。已修。
- **海床「一键恢复」加二次确认，并保留信任记录/引导进度/语言等身份字段**（以前一次点击抹掉全部设置且无提示）。
- **界面不再谎报成功**：网页工具收藏的增删此前只挂事件不落盘（提示"已收藏"后关闭即丢失）；
  节点名过短时提示"已保存"但什么都没写；「自动检查更新」复选框从不写回；
  AI API Key 粘贴后直接关窗会丢失；外部修改冲突确认框永不弹出。
- **市场包事件绑定**：XAML 生成器把事件挂到"文本上最近一个有 x:Name 的元素"，
  元素没名字时会挂错对象 → 点击无效或整包编译失败、小组件静默消失。已改为解析真实宿主元素，
  无法确定时明确报诊断而不是猜。
- **发布版里海床插件"全都不编译"（发布阻断，最隐蔽的一个）**：单文件发布下插件编译链拿不到程序集
  （`构建程序集引用 0 个`），内置小组件在用户机上落不了盘 —— 也就是**你自己造的组件/面板在发布版里
  完全无效**，而 6 个内置件会静默回退内置实现、功能不丢，所以长期没被发现（开发机与 CI 都在源码树里，
  两者都测不出来）。已修：发布配置加 `IncludeAllContentForSelfExtract`、内置件源码改为嵌入资源
  （不再依赖源码目录是否存在）。
- **最近使用列表排序失真**：读取 UserAssist 记录时字段偏移取错（`0x04` → `0x3C`），整张列表排序都不对。
- **AI 助手**：英文界面下会话标题永远显示「新对话」（现按首条消息生成标题）；回复可导出为 `AI 回复.md`；
  密钥加密失败不再覆盖已保存的密钥。
- **媒体面板**按钮文案精简为「镜 / 嵌」。

### 市场与 CI
- **CI 包校验与客户端完全同判**：补上 `.xaml.cs`（此前只看第一个 `.xaml`）、
  真实编译 XAML 形态、并真实实例化（`Activator`）—— 由此发现并修好三个**已发布但装不上的包**：
  `textai`（代码后置直连宿主划词 API，会被沙箱拒装）、`clipboard` / `note`
  （只有带参构造，运行时无法实例化）、`calculator` / `clipboard`（大量事件元素缺 `x:Name`）。
- CI 增加：NuGet 缓存、PR 上的 Release 发布空跑、被跟踪工具的编译、tag 版本号格式校验；
  权限收敛为默认只读（仅发布 job 需要写）。
- **市场发布归属校验**：以前任何人都能覆盖别人的市场包；现在新包必须占自己的命名空间、
  已有包的 `publisherId` 必须是你自己，缺归属信息一律拒绝。

### 卸载与自动更新
- **卸载不再可能删掉你自己的文件（重要）**：以前判断"安装目录"的方式是**看目录里有没有 `ShoreHue.dll`**，
  有就整套递归删 —— 而本版发布的是**单文件 exe**，很多人直接在 `Downloads\` 或桌面双击运行，
  那一下会把**整个下载夹**一起删掉。现在改为：**只删文件名以 `ShoreHue.` 开头的文件，从不递归删目录**。
  自己的文件删完后目录若为空才删目录；**仍有残留就原样保留**（可能是第三方依赖，也可能是你的文件），
  并在**桌面**留一份 `ShoreHue-卸载残留说明.txt` 告诉你目录在哪、怎么处理。干净卸载不会往桌面写任何东西。
  （成熟安装器靠安装清单做到"既删干净又不误删"；ShoreHue 没有安装步骤、拿不到清单，所以选择保守一侧。）
- **卸载日志不再乱码**：卸载脚本由 Windows PowerShell 5.1 执行，它的 `Add-Content` 默认按系统 ANSI
  （简中即 GBK）写文件 —— 日志里的中文在 UTF-8 环境下读出来是乱码。现改为写无 BOM 的 UTF-8。
- **开始菜单快捷方式会自愈**：卸载（或手动清理 `bin`）删掉安装目录后，快捷方式以前只检查
  「文件在不在 + AUMID 对不对」，**不看它指向的 exe 是否还在** → 变成死链、点了没反应且永不修复。
  判据现已补上「目标就是当前这个 exe，且它确实存在」，应用启动时会自动重建（通知功能依赖它注册）。
- **自动更新挑包更稳（本版新增 zip 资产后的必要修正）**：更新包的选择从"取第一个 `.exe`/`.zip`"
  改为**优先精确匹配 `ShoreHue.exe`**。原因是资产顺序变化后，若挑到 zip，客户端会拿 exe 的 SHA256
  去比对 → 校验不匹配 → 按 fail-closed 设计**拒绝安装**，等于自动更新静默失效。
- **自动更新改为 fail-closed**：发布说明里没有 SHA256 时**默认拒绝安装**（旧行为是直接装），
  并弹窗征询「仍要继续安装吗？」；下载失败会区分「网络问题 / 缺少校验值 / 校验不匹配」并给出相应出路
  （以前一律提示"下载失败，请检查网络"，而"缺校验值"重试一万次也不会成功）；校验不匹配任何时候都不放行。

### 本版资产
- `ShoreHue.exe` —— 单文件版，**自动更新的下载对象**（发布正文中的 SHA256 即此文件）。
- `ShoreHue-v1.1.1-win-x64.zip` —— 整包（exe + README + LICENSE + AI 编程指南），解压即用。
- `ShoreHue-1.1.1-x64.msix` —— 商店/MSIX 安装包（未签名）。

### 构建
- **零告警构建**：主工程与测试工程均开启 `TreatWarningsAsErrors`。
  本版清掉了 10 条可空性/异步告警，以及多余包引用（NU1510）与清单 DPI 告警（WFO0003）——
  那些可空性告警正是上面几条空引用与丢失路径的静态证据。
- 显式声明 `TargetPlatformMinVersion`（把"支持 Windows 10 1809+"交给编译器校验），
  修掉"README / MSIX 清单说 1809、二进制实际编译目标却是 19041"的口径不一致。

## v1.1.0

> 品牌焕新：**灵动鸟 DynamicBird → ShoreHue 海岸线**。产品名、代码、数据目录全面更名（旧配置数据已清理，不做自动迁移）。界面同时移除全部 emoji 图标，改用文字与矢量图标。

### 新品牌
- **ShoreHue 海岸线**：Shore（岸）+ Hue（色彩）——桌面边缘即海岸，岸上、岸下都丰富多彩，色彩随潮汐而动
- 编程生态「鸟笼」更名为 **海床**：文件夹即真相源的编程模式不变，功能像种子一样种进海床、自动生长
- 在线市场动语更新：发布功能 = **放流**（放流入海），安装功能 = **拾贝**（岸上拾贝）；界面不再使用吉祥物表情

### 新功能

**1. 海床：完全编程 / 完全编译（XAML + 代码后置）**
- 小组件与面板功能支持**完整 WPF 用户控件**：.xaml 界面 + .xaml.cs 代码后置，事件、绑定、样式全部可用——不再只是纯 C# 拼控件
- **VS Code 式双编辑器**：.xaml / .xaml.cs Tab 切换，底部**实时预览**；保存即编译，报错内联显示
- 编程模式区分：**简单编程**（纯 C#，快速原型）与**完全编程**（XAML 形态，完整控件）；AI 提示词按所选模式生成
- **海床 = 内置文件资源管理器**：树 = seabed 文件夹的真实目录扫描；点文件读真文件、编辑保存写回、删除走回收站；外部改动保存前提示覆盖，IO 失败重试不静默
- **文件夹即真相源强化**：小组件 XAML / 面板 main.cs / 状态栏配置全部直接从 seabed 文件夹读取真实内容
- **海床市场多形态协议**：功能包支持 manifest 文件清单 + 多文件上传/下载，按分类落盘，预览标注格式；五个内置小组件包更新为 XAML 形态

**2. 数字环（键盘呼出 16 区域）**
- 设置 → 区域 → 高级开启后，按**修饰键 + 数字 1-9**（主键盘或小键盘均可）直接呼出对应区域面板：7/9/1/3 四角、2/4/6/8 四边中段
- 精修组合：边键 + 邻角键（如 4+7 = 左边缘上段小组件）呼出**边端段**面板；再按一次收起
- 修饰键可改（默认 Ctrl，可选 Ctrl+Shift / Alt / Ctrl+Alt）；右上角默认安全区不呼出
- 键盘呼出的面板**钉住不自动隐藏**，配合「跟随鼠标/固定贴边」使用

**3. 其他新功能与改进**
- **界面字号缩放全局生效**：设置 → 面板 → 外观的字号滑块（75%~150%）现在对**桌面各面板**（任务栏 / 小组件 / AI 等）即时生效，不只是设置窗口
- **媒体控制修正**：上一首 / 下一首图标方向改正；移除底部冗余的「系统媒体键兜底」横条，界面更干净
- **设置窗口可拖拽调整大小**恢复（含左下角），原生窗口缩放边框重新启用

### 稳定性与体验改进
- **海床 watcher 重构**：按 VS Code 风格时间窗口聚合文件事件，事件合并不丢失、不再卡死；移除旧的 800ms 丢弃式防抖
- 应用图标改版：海蓝→沙滩 45° 渐变 + 透明二维码（icon.ico / MSIX logos / Store 图全部同步重生成）

## v1.0.5

> 本版聚焦「AI 编程生态」：**状态栏插件 + 自定义动画代码化**，让 AI 与用户一起为 ShoreHue「长出」新功能。

### 新功能

**1. 状态栏插件（AI 可编程）**
- 新增 `IStatusProvider` 接口：AI 生成 C#（如 CPU 温度、网速、股票）放入 `seabed\状态栏\` 自动编译挂载到状态栏
- 状态栏插件有独立开关、默认启用，卸载自动释放资源

**2. 自定义动画（AI 可编程）**
- 新增 `IAnimation` 接口：AI 生成 C#（如弹跳、翻转、粒子）放入 `seabed\动画\` 后可在设置中选作呼出/隐藏动画
- 动画执行带三重保护：异常回退内置动画、超时强制完成、完成回调幂等——杜绝卡死

**3. 全局界面字号缩放**
- 设置 → 面板 → 外观：字号滑块（75%~150%），所有界面即时生效

**4. 海床增强**
- 「AI 编程指南」按钮：打开完整 AI 编程教程（能做什么/不能做什么/各类格式）
